# 简单的航班导航算法：飞行路径规划、最短路径计算

## 如何构建编译：

### 仅适用于 Windows

- 安装 `gcc`。
- 你可以通过安装 `MinGW` 来安装 `gcc` 编译器。
- 点击运行 `build.bat` 或在终端运行以下命令：

```bash
makefile.bat
```

# Simple flight navigation algorithm: flight path planning, shortest path calculation

## How to make

### Only for Windows

- Install the `gcc`.
- You can install `gcc` compiler by installing `MinGW`.
- Click `build.bat` or run the following commands in the terminal:

```bash
makefile.bat
```
